A first programming course. No prior experience assumed.

The course is taught in four blocks of three weeks. Each block ends with a
portfolio checkpoint, and the portfolio you submit is the work you have already
been doing, tidied up and explained.

| Block | Weeks | Topic |
| --- | --- | --- |
| 1 | 1–3 | Values, names and expressions |
| 2 | 4–6 | Making decisions and repeating work |
| 3 | 7–9 | Structuring a program |
| 4 | 10–12 | Working with data |

This course is in the prototype mainly to demonstrate switching between courses
and combining deadlines and feedback from more than one place. It carries fewer
resources than *Seeing Through Obfuscated Code* by design.

All course data here is fictional.
